# MadridAccidentsML

## Análisis de accidentes de tráfico en Madrid

Proyecto académico realizado durante mi formación en Python, Big Data e Inteligencia Artificial en Grupo Atrium.

El objetivo de este proyecto es practicar el análisis de datos y aplicar técnicas básicas de Machine Learning utilizando información sobre accidentes de tráfico en Madrid.

## ¿Qué he trabajado?

- Exploración y limpieza de datos.
- Análisis de variables relacionadas con los accidentes.
- Visualización de datos mediante gráficos.
- Preparación de datos para Machine Learning.
- Entrenamiento de un modelo de clasificación mediante regresión logística.
- Pruebas de predicción con nuevos datos.

## Herramientas utilizadas

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn y Jupyter Notebook.

## Organización del proyecto

- `notebooks/`: análisis exploratorio de los datos.
- `models/`: código del modelo de clasificación.
- `scripts/`: entrenamiento y pruebas de predicción.
- `requirements.txt`: librerías utilizadas.
